# ⛺ Daddycamp App

Private Web-App mit Firebase Echtzeit-Sync.

## Setup

1. `.env.example` kopieren und umbenennen zu `.env`
2. Firebase API-Key eintragen
3. In Vercel: Environment Variable `VITE_FIREBASE_API_KEY` hinterlegen

## Lokal starten
```bash
npm install
npm run dev
```

## Deployment
GitHub → Vercel → automatisch deployt.
